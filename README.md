## Принцип работы:
- Участники заполняют календарь прямо на сайте.
- Организатор задаёт параметры встречи: желательная дата, длительность, список участников.
- Система автоматически анализирует занятость всех участников.
- Приложение предлагает несколько оптимальных временных слотов, когда все свободны.
- Организатор выбирает подходящий вариант и подтверждает встречу.
- Система автоматически создаёт событие в календарях всех участников.

## Основные функции MVP
**Личный календарь**:
- Отображение занятых и свободных временных слотов
- Возможность редактирования своей занятости
**Создание группы**:
Пользователь задаёт название группы и приглашает участников
**Создание встречи**:
Пользователь выбирает группу, для которой хочет создать встречу, и указывает:
- длительность встречи
- временной диапазон
- комментарий
**Подбор времени**:
Система автоматически анализирует занятость участников и организатор может выбрать из предложенных оптимальных временных слотов
**Появление встречи**:
- Выбор организатором подходящего слота
- Создание события в календарях
**Авторизация**:
Регистрация и вход (email, пароль, ФИО)

## Технические моментики
- состояние календаря хранится в глобальном объекте, потому что это самый простой вариант и он работает
- мини календарь и сетка большого календаря создаётся целиком через js, потому что в html прописывать муторно и можно ошибиться
